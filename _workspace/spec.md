# 📋 작업 명세서 (Work Spec) - Issue #1

* **이슈 번호**: #1
* **작업 제목**: 배경 바꾸기 (배경 검정 → 화이트 변경)
* **담당 에이전트**: `worktree-coder`
* **요구사항 원문**: "배경 검정인데 화이트로 변경하고싶다"

---

## 1. 작업 목표 (Goal)
Galaxy S25 랜딩 페이지의 전체 배경을 기존 블랙(#000)에서 밝고 깨끗한 퓨어 화이트(#ffffff)로 전면 전환하고, 텍스트 가독성을 보장하기 위해 글자 색상을 최적화한다.

## 2. 작업 범위 및 대상 파일 (Scope)
* **수정 대상 파일**: `css/styles.css`
* **핵심 변경 내역**:
  1. CSS 변수 `--bg-primary` 및 `body` 배경색을 `#ffffff` (화이트)로 수정.
  2. 텍스트 색상(`--text-primary`, `--text-secondary`)을 밝은 배경에 맞춰 다크 톤(`--text-primary: #111111`, `--text-secondary: #555555`)으로 조정하여 명도 대비 확보.
  3. 헤더 네비게이션, 카드 배경(`--card-bg`) 등의 명도 및 테두리 선(`border`)을 라이트 모드 규격으로 보정.
  4. 다른 기능(JS 인터랙션, 버튼 클릭, 레이아웃 그리드)은 일절 변경하지 않는 외과적 변경 수행.

## 3. 완료 기준 (Acceptance Criteria)
- [ ] 전체 페이지 배경이 화이트(#ffffff)로 표시될 것.
- [ ] 본문 및 타이틀 텍스트가 배경에 묻히지 않고 선명하게 가독성을 유지할 것 (WCAG 명도 대비 충족).
- [ ] 정적 구문 오류(HTML/CSS)가 없을 것.
- [ ] 헤드리스 브라우저를 통한 Before & After 스크린샷 증거가 디스크에 생성될 것.
